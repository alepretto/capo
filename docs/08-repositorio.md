# Repositório

Um repositório só, `alepretto/capo`, até o diário existir.

Web de teste, API e o app do Pixel depois ficam no mesmo lugar. A versão confirmada, o PDF e o código FIPE são o mesmo contrato. Separar agora cria dois históricos para uma pessoa.

```
docs/     desenho
web/      bancada do cadastro, no navegador do Pixel
api/      processo que recebe o PDF e devolve os campos
app/      diário no aparelho, quando a ficha confirmar sem erro
```

`web/` não é o produto. Some, ou vira só consulta, quando o app assumir o lançamento offline.

Não separar enquanto a mudança de um lado exigir a do outro no mesmo dia. Separar se um dia o app tiver ciclo de loja próprio e a API tiver outro dono. Não é o caso.
