# Funcionalidades

Primeiro corte pensado pelo dono do projeto. Isto confirma a ficha. Ainda não é o diário.

## 1. Conta

- Nome
- E-mail
- CPF

O CPF continua só da conta, cifrado, e não sai para API de placa. Serve para conferir o proprietário do CRLV-e.

## 2. Veículo

- Upload do CRLV-e. É o caminho que confirma.
- Digitar placa, RENAVAM e o resto continua existindo, e deixa a versão `nao_confirmada`.
- Confirmação exige o PDF, CPF batendo com a conta, e a escolha explícita da linha FIPE. O arquivo sozinho não fecha a versão comercial.

## 3. Depois da versão confirmada

- Manual. A Volkswagen publica o PDF do Polo em vw.com.br e reserva a reprodução. O app aponta para o link oficial do ano certo. Não hospeda o manual. Se a pessoa tiver o arquivo dela, pode anexar.
- Desenho 3D. Não é o carro inteiro em CAD. É o Polo da versão confirmada, com as peças que mudam a duração: óleo e filtro, filtro de ar, velas, correia, freio, embreagem. Cada peça abre o registro dela, não uma animação solta.

## O que este corte não faz

Sem hodômetro, abastecimento, serviço feito e exportação, o Capô é uma ficha com um modelo. O diário é o corte seguinte, pendurado na versão confirmada.
